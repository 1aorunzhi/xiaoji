# 创作说明

**为什么选这个题**

多数 AI 陪伴太懂事，温柔正确的不是伙伴，是客服。真实关系有摩擦，所以「记仇」是核心：它记的不只是事实，还有你欠的。两个高潮：小圆片冒出「记仇·你答应早睡没做到」；道歉它不接反而加价，只有真喂一罐才翻篇。

**怎么做的**

后端 Python，FastAPI + SQLite，前端只负责画。提示词、成长数值、记仇开价、食物消化、存档全在 Python；回复流式推回浏览器，复盘另起一次调用，把闲聊压成「事」。模型走云端免密钥。

**踩了什么坑**

第一版它张口「抱抱你」，只好列禁区、加代码闸门。喂到 Lv.10 才发现只是变大的同一颗球，改成一部件一等级长出来。最坑的是它太好哄——一道歉就原谅，跟记仇簿打架；改成只认补偿、会加价，再补个能喂进去的食盆。它还会嘴上说一套账上记一套，把当前价做成紧贴输出的消息才压住。

**如果发布**

标题《我养了一只 AI，它会记仇》，小红书首发，公众号发教程。
