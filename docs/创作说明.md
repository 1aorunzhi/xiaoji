# 创作说明

**为什么选这个题**

多数 AI 陪伴太懂事，温柔正确的不是伙伴，是客服。真实关系有摩擦，所以「记仇」是核心：它记的不只是事实，还有你欠的。两个高潮：小圆片冒出「记仇·你答应早睡没做到」；道歉它不接，反而加价，只有真喂进去一罐才翻篇。

**用了什么工具，踩了什么坑**

用 WorkBuddy，模型走云端免密钥。第一版它不肯当宠物，张口「抱抱你」，只好列禁区、加代码闸门。第二个坑：喂到 Lv.10 才发现只是变大的同一颗球，改成一部件一等级长出来。最坑的是它太好哄——一道歉就原谅，跟记仇簿打架；只认补偿、会加价，再补一个能真喂进去的食盆，才立住。最后发现吃进去的东西凭空消失，于是补了消化：吃了会拉，不收拾会掉心情，堆久了还得记一笔仇。

**如果发布**

标题《我养了一只 AI，它会记仇》，小红书首发，公众号发教程。
