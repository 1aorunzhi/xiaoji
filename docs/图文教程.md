# 我养了一只 AI，它会记仇

> 「你昨天也这么说的……结果还不是喂完我就倒头睡。」

这句话不是我写的。是我养的一只东西说的——它叫年糕，住在网页里。第二天，它就自己翻出了我说过的话：

**「记着呢，连你说谎的日子都算好了。」**

那一刻我后背发凉。

---

## 它到底是什么

不是聊天机器人。

输入框上面蹲着一个圆圆的、会呼吸的小东西。你打字，就是在喂它。

你问天气，它大概率回「明天的事明天说，先给我弄点吃的」。

它只做四件事：

**记事。** 关键信息压成一句，下次自己翻出来。

**记仇。** 进了「记仇簿」的事，道歉没用。它当场开价，你再道歉就加价，东西真给了才翻篇。

**长大。** 每喂一次升一级，身上真会长东西。

**变性格。** 你怎么说话，它往哪边漂：毒舌还是温柔、混沌还是理智、社恐还是社牛。

## 为什么我要做一个「记仇」的宠物

AI 陪伴产品大多死在**太懂事**上。你难过它安慰你，你累它让你休息，聊三次就腻——永远正确温柔的不是伙伴，是客服。

真实的关系里有摩擦。朋友记得你放过他鸽子，猫会在你出差三天后把杯子推下桌。**「记仇」是这个产品里最像活物的一根刺。**

所以我把记忆和情绪绑在一起：它记的不只是事实，还有你欠它的账。

而且它不接受道歉。「对不起」只是欠条：第一次开价「陪我玩十分钟」，第二次半小时，第三次一整晚。东西到手才翻篇。

## 我往它身上塞了五样东西

### 一、它记的不是聊天记录，是「事」

全塞进上下文，几轮就又慢又贵又跑题。所以我让模型每轮结束后**再做一次「复盘」**——把「我今天面试挂了，好烦」压成一条：

> 主人今天面试失败了，很烦

存进一个小本子，四十条封顶。下次只挑相关的几条塞回去。它记的是结论，不是流水账。

![](./screenshots/03-对话与记忆.png)

那些小圆片是它刚记下的东西，黄色是事实，红色是记仇。**你能实时看见它在记住你。**

### 二、性格是养出来的，不是设定的

大部分 AI 角色的人设写死在提示词里。我不想要，我想要「我把它养成了这样」。

每轮对话，模型除了回复还会输出一组数字：这轮让它的毒舌、理智、社牛各变多少，累积起来决定称号。

你天天吐槽，它就越来越毒；天天哄，就越来越黏。

同一个产品，两个人养一周，会养出两只不同的东西。

### 三、它会因为你不在而生气

页面关掉时间还在走。离开几小时，心情就掉，身体变灰、嘴角垂下来。下次打开，它先开口：

> 「忙到连只猫都喂不上？胖的那个年糕，怕是比我还沉了吧。」

![](./screenshots/05-久别重逢.png)

这句不是我写的。它知道我养了猫，拿这个来刺我。

### 四、它是真的在长东西

![](./screenshots/06-六个阶段.png)

喂到第 28 次，20g 变 596g，Lv.1 到 Lv.10，称号从「还没长出性格的小东西」变成「嘴上不饶人的社交恐怖分子」。

但数字不算养成。真正觉得成了的，是它身上多出来的东西：Lv.3 耳朵、Lv.5 小手、Lv.6 尾巴、Lv.8 皱眉竖瞳、Lv.10 斑纹、Lv.11 脚底光环。

第一版只改尺寸，满级才涨 16 像素。现在部件平时缩在身体里，到等级才弹出来；身体再从矮胖拉长。

### 五、光说话不够，得加个真食盆

聊着聊着我一直在做傻事：说「给你买罐头」，然后什么都没发生。

所以底部多了个碗：小鱼干、猫条、罐头、三文鱼，还有一坨你也不知道是什么。点一下，食物飞到嘴边，它嚼两下自己评价。

口味出生那刻就定死：爱吃罐头的不碰三文鱼。喂过一次才露馅，食盆上多颗星。它也会饱，饱了硬塞就摇头。

它开的价要是「一顿罐头」，你真喂一罐，这笔账当场划掉。

**道歉没用，罐头有用。**

### 六、然后它开始拉屎

食盆刚上线我就发现：吃下去的东西凭空没了。

于是加了消化：吃多少攒多少，攒够就在脚边拉一坨。地上有东西心情就往下掉，它自己会开口催：「地上那两坨，你打算供着？」

得把地上全弄干净它才吭声，剩一坨只说数字。堆到第三坨还搁一晚，它把这事写进记仇簿：「主人让我踩在自己拉的东西上。」

喂 → 吃撑 → 拉 → 不收拾 → 记仇，这条链全程看得见。

## 它是怎么搭起来的

浏览器后面站着一个 Python 后端。

```
你打字
  └─→ POST /api/feed
        ├─→ 当场结算：经验、饱腹、记仇、开价
        ├─→ ① 调模型流式生成回复 ──→ 一个字一个字推回浏览器
        └─→ ② 再调一次模型做复盘 ──→ 写进 SQLite ──→ 变成那颗小圆片
```

为什么拆两次？一边流式一边吐 JSON，模型会精神分裂。

前端只剩一层壳：收到 `state` 重渲染，`delta` 打一个字，`chip` 弹圆片。`ui.js` 里没有任何业务计算。

**为什么从纯前端搬到 Python。** 最早所有逻辑都在浏览器里，双击就能跑。要交给一个 Python 岗，我把状态机、提示词、记忆、存档整体搬到了 FastAPI 上。

那些逻辑本来就是纯函数，照着翻就行。卡住的是模型调用：认证头不是标准的 `Authorization: Bearer`，抓了三遍浏览器的真实请求才发现要传一个自定义头。

## 你自己也能跑起来

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
python run.py
```

打开 `http://127.0.0.1:8000`。

后端在 `app/`，前端在 `web/`。想改性格改 `app/brain.py` 的 `build_system_prompt()`，把「不要卖萌」改成「要多撒娇」，它就变成另一只宠物。

## 它翻车的地方（比成功更有用）

**第一版它是个舔狗。** 我期待「嘴硬的小东西」，它给我「抱抱你，下次一定会更好的」。只好在提示词里列禁区：**你是宠物，不是情感博主。**

**第二版它每条都带括号动作。** 提示词写了「三句最多一次」，它当没看见。代码里加了个闸门：上一条用过，这条就剥掉。**提示词不是写完就完事，得有兜底。**

**第三版它卡在「吃」上。** 聊四句有四句在讨食，只好加规则：上一句提过吃，这句换话题。

**第四版它太好哄。** 最早写「一道歉就原谅」，结果它嘴上说"勉强原谅你"，档案里那笔账还红着。改成道歉只开价、再道歉加价；模型又老自己编"五块七块"，只好把价钱钉死在提示词最后。

**第五版它嘴上说一套、账上记一套。** 账上写「一整条三文鱼」，它开口「三块小鱼干」——历史对话里有旧报价，它顺着旧的往下说。提示词改了三遍压不住，最后把当前价做成一条紧贴输出的消息才管用。**模型更容易相信离它最近的那句话。**

## 最后

一开始想做「接进 QQ 的大模型宠物」，但审核和服务器都不由自己，就搬进了网页——**「养」的爽点来自记忆、性格和它主动找你，跟在哪个 App 里没关系。**

现在它记得我面试挂了，记得我有个胖猫，记得我独自吃了两碗面没带它。

你要不要也养一只？

> 你大概率会想试试对它说「我明天一定早睡」。
